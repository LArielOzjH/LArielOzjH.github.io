Determinism is not a single switch. In long inference pipelines, repeatability depends on model code, runtime kernels, batching policy, cache state, and even logging boundaries.

## Layers

- deterministic math
- deterministic scheduling
- deterministic input construction
- deterministic observation

## Local rule

The note should say which layer it is claiming to control. Without that sentence, a reproducibility claim becomes too broad.
